# Exempelinnehåll

Två filer som visar formaten innan schemat är implementerat:

- `fragor-03-lovplikt.yaml`: fyra frågor av olika typ ur modul 3.
- `A002-tillbyggnad-bjorken-7/arende.yaml`: ett nivå 2-ärende med handlingar, steg,
  händelser och bedömningspunkter. Handlingarna (PDF/SVG) finns inte ännu; mappen visar var de ska ligga.

Lagrumshänvisningarna är skrivna efter bästa förmåga men ska granskas av handledaren innan
de används som facit.
