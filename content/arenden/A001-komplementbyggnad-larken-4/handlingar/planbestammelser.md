# Detaljplan för Lärkbacken, del av Åkerslunda 1:1

**Åkerslunda kommun** · Laga kraft 1991-09-23 · Beteckning Dp 1991-07

> Planen upprättades enligt plan- och bygglagen (1987:10). Genomförandetiden var tio år och
> har gått ut. Utdrag ur planarkivet.

## Planbestämmelser

Följande gäller inom områden med nedan angivna beteckningar. Där beteckning saknas gäller
bestämmelsen inom hela planområdet.

### Användning av mark

| Beteckning | Bestämmelse |
| --- | --- |
| **GATA** | Lokaltrafik. Allmän plats, kommunen är huvudman. |
| **NATUR** | Naturområde. Allmän plats, kommunen är huvudman. |
| **B** | Bostadsändamål. Friliggande en- eller tvåbostadshus. |

### Utnyttjandegrad

| Beteckning | Bestämmelse |
| --- | --- |
| **e₁ 25** | Största byggnadsarea är 25 procent av fastighetsarean. Byggnadsarean för huvudbyggnad och komplementbyggnader räknas samman. |

### Begränsning av markens bebyggande

| Beteckning | Bestämmelse |
| --- | --- |
| **Prickmark** | Marken får inte bebyggas. Inom kvarteret Lärken ligger prickmarken i en 6,0 meter djup zon längs gränsen mot gata. |

### Placering och utformning

| Beteckning | Bestämmelse |
| --- | --- |
| **II** | Huvudbyggnad får uppföras i högst två våningar. |
| | Huvudbyggnad ska placeras minst 4,5 meter från tomtgräns. |
| | Komplementbyggnad får placeras närmare tomtgräns än 4,5 meter, dock minst 1,0 meter. |
| | Komplementbyggnad får ha en byggnadshöjd om högst 3,0 meter. |
| | Takvinkeln får vara högst 30 grader. |

### Administrativa bestämmelser

Genomförandetiden är tio år från den dag planen vann laga kraft. Någon särskild bestämmelse om
utökad lovplikt eller om undantag från lovplikt finns inte i planen.
