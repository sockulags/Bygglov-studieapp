# Detaljplan Dp 1986-03 för kvarteret Tallen m.fl.

| | |
| --- | --- |
| Laga kraft | 1986-05-12 |
| Genomförandetid | 15 år, gick ut 2001-05-12 |
| Gäller för | Tallen 1–12 och angränsande gata |

## Användning

**B** Bostäder. Friliggande en- och tvåbostadshus.

## Utnyttjandegrad och utformning

| Bestämmelse | Innehåll |
| --- | --- |
| Huvudbyggnad, största byggnadsarea | 160 m² per fastighet |
| Huvudbyggnad, högsta byggnadshöjd | 4,5 m |
| Komplementbyggnader (garage, uthus), största byggnadsarea | Sammanlagt 45 m² per fastighet |
| Komplementbyggnader, högsta byggnadshöjd | 3,0 m |
| Takvinkel | Högst 27° |

## Planbeskrivningens syfte (utdrag)

"Planen syftar till ett område med friliggande småhus i en våning med låga uthus och garage,
så att tomterna får ljus och utsikt och grannarna inte störs av höga byggnader nära
tomtgränserna."
